# Viaje

### 프로젝트 소개
---
#### 나의 계획? 너의 경험!
> 여기서 추천하는 이 식당이 정말 맛있는 곳인가?  
> 이 관광지가 정말 내가 하루를 투자해서 가볼만 할까?  
> 다른 사람들은 어떤 걸 하고 왔지?
</br>
여행 계획을 세우다 보면 계획 세우기에만 며칠씩 걸리곤 합니다.

다른 사람들의 여행 계획을 참고하거나 그대로 따라 가보고 싶을 때, 


**Viaje**는 이런 여행 계획을 더 쉽게 공유하고 찾을 수 있도록 돕는 여행 계획 공유 사이트입니다.

### 기능
---
- **여행 계획 등록**: 사용자가 다녀온 여행 계획을 업로드 할 수 있습니다. 관리자 승인을 거쳐 최종 등록되면 다른 사용자가 계획을 볼 수 있습니다.
- **여행 계획 목록 조회 및 검색**: 사용자는 다양한 여행 계획을 조회하고, 태그를 통해 검색할 수 있습니다.
- **여행 계획 구매**: 여행 계획 구매 시 상세한 계획을 확인할 수 있습니다.

### 기술 스택
---
- **프론트엔드**: HTML, CSS, JavaScript
- **백엔드**: Java (Spring Boot)
- **데이터베이스**: MySQL
- **결제 서비스 연동**: 토스페이먼츠 API

### 팀
### **양혜지**
- **기능**: 계획 등록, 태그 기능, 등록된 계획 상태에 따른 목록 표시, 포인트 충전, 계획 구매, 장바구니, 좋아요 기능, 마이페이지를 통한 포인트 구매 계획 좋아요 내역 조회,


### **정창열**
- **기능**: 회원 가입, 로그인 기능, 댓글 기능, 등록된 계획 상태 관리


### **이주형**
- **화면**: 전체 화면 디자인 및 구현
- **기능**: 회원가입 유효성 검사, 메인 메뉴 드롭다운 바
